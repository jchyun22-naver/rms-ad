# RMS 사이니지 Android TV 앱

기존 RMS 서버의 홍보 이미지·동영상·배경음을 재생하는 별도 Android TV 앱입니다. 화장실 관리, 센서, 비콘 기능은 포함하지 않습니다.

## 주요 기능

- RMS 시험/운영 서버에서 설치 위치와 홍보 콘텐츠 선택
- 이미지·영상 순환 재생과 오프라인 캐시
- 리모컨 확인(OK) 버튼으로 관리자 PIN 창 열기. PIN이 맞으면 관리자 화면 자동 진입
- 가로/세로 방향, 콘텐츠 맞춤, 목표 해상도, 이미지 재생 시간, 음악·영상 볼륨 설정
- HDMI 정보 확인과 전체 화면 시험 패턴
- 앱 설정 및 저장 콘텐츠 초기화

## Windows 노트북에서 빌드

1. JDK 17 이상과 Android SDK를 설치합니다. Android SDK Platform 33과 Build Tools가 필요합니다.
2. 프로젝트 루트에 `local.properties`를 만들고 SDK 경로를 지정합니다. 예: `sdk.dir=C\:\\AndroidSdk`
3. PowerShell에서 `./gradlew.bat :app:assembleDebug`를 실행합니다.
4. APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다.

`local.properties`, 생성 APK, 서명 키는 Git에 포함하지 않습니다. 이 프로젝트를 노트북에서 처음 빌드하면 노트북의 새 디버그 키로 서명됩니다. 기존 TV 설치본을 **삭제하지 않고 업데이트**하려면 기존 설치본과 같은 서명 키가 필요합니다. 설치 위치와 캐시를 보존해야 한다면 기존 키를 안전한 별도 경로로 옮겨 사용하세요.

## 현재 시험 범위

- V_BOX14에서 설치와 이미지·영상 재생을 확인했습니다.
- 앱의 `목표 해상도`는 선호값입니다. 실제 HDMI 출력 모드 변경 가능 여부는 기기와 모니터가 보고하는 지원 모드에 따릅니다.
- 현재 서버 연동은 기존 RMS의 위치 ID 기반 홍보 콘텐츠 API를 사용합니다. 전용 사이니지 위치·콘텐츠 관리는 서버와 웹 관리자 기능을 추가해야 합니다.

이 저장소는 시험판 소스입니다. 기기에 설정된 관리자 PIN과 서버 인증 정보는 저장소에 넣지 않습니다.
